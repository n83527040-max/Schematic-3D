## المخرجات المطلوبة
1. صورة مرجعية voxel/Minecraft واضحة.
2. صور منفصلة من الأمام والخلف والجانبين والأعلى، ومن الداخل عند الحاجة.
3. مخططات الطوابق والأبعاد.
4. جدول مواد.
5. ملف JSON كامل بصيغة `schematic3d-build` يحدد كل بلوك وإحداثياته وحالته.
6. تقرير تحقق من الأبعاد والعدد الفعلي والبلوكات غير المؤكدة.
7. إذا لم تستطع إخراج الملف الكامل، صرّح بذلك ولا تخترع رابط تحميل ولا تسمِ العينة «كاملة».

## مخطط JSON
{
  "format": "schematic3d-build",
  "schemaVersion": 1,
  "name": "اسم المبنى",
  "description": "وصف",
  "targetEdition": "bedrock",
  "dimensions": {"x": 1, "y": 1, "z": 1},
  "palette": [{"id": "minecraft:stone", "states": {}}],
  "blocks": [{"x": 0, "y": 0, "z": 0, "paletteIndex": 0}],
  "layers": [{"id": "floor_1", "name": "الطابق الأول", "yMin": 0, "yMax": 0}],
  "rooms": [],
  "metadata": {"generator": "external-ai", "notes": [], "unsupportedFeatures": []}
}

المثال يشرح البنية فقط ولا يمثل مبنى كاملاً. يجب ملؤه بكل البلوكات. كل إحداثية داخل الأبعاد، وكل paletteIndex صالح، ولا توجد إحداثيات مكررة دون تفسير. استخدم معرفات Bedrock معروفة، واكتب block states فقط إذا كنت واثقاً منها.

**قواعد الدقة:** الرندر 3D ليس بيانات بناء. لا تدّع أن JSON ملف mcstructure جاهز؛ هو ملف وسيط يحتاج تحققاً وتحويلاً. افصل الصور عن JSON. إذا كان هناك جزء غير مؤكد فاذكره بدلاً من ادعاء الدقة الكاملة.
